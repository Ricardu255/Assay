# 开发协作笔记

## Harness 工具调用规则

`DeepSeek Messages stream: tool input is invalid JSON` 已多次出现。原因是工具参数 JSON 被截断或转义错误，不是代码/构建失败。

后续约束：

1. 单次 `edit` 的 `new_string` 控制在约 2 KB、20 行以内；大段内容拆成多次。
2. 不把大段代码块、双引号、反斜杠放进同一个 `edit`。
3. 每次编辑前先 `read` 目标附近内容，使用短而唯一的锚点。
4. 失败后先检查文件是否已部分写入，不要原样重发同一大 payload。
5. 文档优先“小段追加/替换”，避免整节重写。
6. 工具调用一次只做一件事，减少长参数和并发大调用。
